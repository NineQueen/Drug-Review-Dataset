## B. Text feature engineering：构造模型输入，使用 `review_clean`、`words`、`words_stem`

- [ ] **B1. 缩写展开（原 TODO 2 的建模部分）**
  - **当前问题：** 仍未展开缩写，后续直接删除标点会产生 `didn`、`t` 等碎片并损失否定表达。
  - **要做什么：** 从已清洗的 `review` 初始化 `review_clean`，先处理特殊形式，再用有边界的通用规则处理常见形式，例如 `didn't → did not`、`can't → can not`。
  - 避免无条件使用任意单词加 `'ll → will` 的规则；数据中的 `ya'll`、`pi'll` 等必须先完成清洗。
  - `'s`、`'d`、`ain't` 等存在歧义，应明确处理或保留策略；保护病名、所有格及医学表达。

- [ ] **B2. 剂量表达规范化（原 TODO 3，与 B3 配合修改）**
  - **当前问题：** `0.5 mg` 在现有流程中会被拆成 `0`、`5mg`，破坏原始剂量。
  - **要做什么：** 同时识别整数、小数与单位，使 `0.5 mg`、`0.5mg` 表示一致，且区别于 `5mg`；保留原数值，不猜测修正剂量。

- [ ] **B3. 调整分词规则（原 TODO 4）**
  - **当前问题：** 删除所有非字母数字字符会破坏小数、剂量和需要保留的撇号表达。
  - **要做什么：** 配置 `RegexTokenizer` 的有效 token 规则，配合 B1、B2 保护所需表达；不能只更换工具名称而沿用默认规则。
