# TF-IDF 随机森林严格对照说明

四组均重新训练；TF-IDF、病症、日期、票数特征、100 棵树、seed=42、全部数据划分相同。
较弱正则化：maxDepth=10，minInstancesPerNode=5。较强正则化：maxDepth=8，minInstancesPerNode=20。
不加权指不传 weightCol；加权只在训练中使用 n/(10*类别频数)，不做采样。Precision/F1 均按原始类别支持度加权。
四组方案均在查看本轮测试指标之前确定；测试集此前已被观察，本轮属于同一划分上的重复对照，未做多随机种子检验。
最初 16/10 深度、256 MB 直方图方案发生 Java heap space，失败日志单独保留，未填入有效结果。随后四组均改为相同 64 MB 预算并重新训练。

文件：测试集对照表.csv 为四组测试结果；增长变化表.csv 为配对变化；metrics.csv 为 train/valid/test 全部指标。
Accuracy、Precision、F1 变化使用百分点，正值表示上升；MAE、RMSE 使用原评分单位，负值表示误差下降。
这些是相对正则化强弱，不是 L1/L2。较浅树并不保证泛化更好。训练耗时为墙钟时间，不据此比较速度。

测试集配对结论：
- 不加权时加强正则化：Accuracy -0.099 个百分点，F1 -0.209 个百分点，MAE +0.0099，RMSE +0.0101。
- 加权时加强正则化：Accuracy +0.018 个百分点，F1 -0.140 个百分点，MAE +0.0293，RMSE +0.0470。
- 较弱正则化时启用权重：Accuracy +2.318 个百分点，F1 +16.624 个百分点，MAE -0.7113，RMSE -0.8757。
- 较强正则化时启用权重：Accuracy +2.435 个百分点，F1 +16.693 个百分点，MAE -0.6919，RMSE -0.8388。

已独立复算四组测试集五项指标，核对 22,220 个 ID 与标签、模型参数及差值公式，均通过。
原 200 棵树、深度 16、测试 Accuracy=0.360036 的默认模型未被替换，与原检查点逐文件校验一致。
